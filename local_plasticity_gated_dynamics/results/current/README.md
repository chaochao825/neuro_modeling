# Current evidence view

This view contains only evidence that remains part of an active contract:
high-rank physical E/I substrates, low-dimensional credit/effective control,
hidden belief inference, bounded actuator studies, and the Exp39
factorized-uncertainty composition result. Superseded prefix, change-point,
and scalar-retention methods live only in the historical view.

Every `support`, `oppose`, or `inconclusive` label is scoped to the registered
experiment. Exp39 supports aggregate generalization to unseen h/Q/R
compositions, not calibrated parameter recovery, universal cell-wise
dominance, or faster switching. The active real-neural endpoint (Exp25)
remains fail-closed and inconclusive.

`claims.csv` is the lossless current-only split of the legacy mixed
`results/summary.csv`; no historical claim row is present in it.
`foundation_claims.csv` extracts the still-active Exp08/09 rows from
their hash-bound ancestor snapshot without importing superseded claims.
